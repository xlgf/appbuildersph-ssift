# ssift

**Ask your screenshots anything, offline.** ssift is an Android app that reads every screenshot on your phone with on-device AI. It sorts them into folders built from what you actually keep (chats, receipts, schedules, logins, games, memes). It answers questions like "what's the Wi‑Fi password at Mom's?" or "where did I park?" in a few seconds, and says "not sure" instead of guessing. It also flags screenshots that expose card numbers, passwords or ID numbers. The app has no internet permission, so nothing can leave the phone.

Built for the AppBuilders PH hackathon, theme "Local AI".

## What runs locally

Everything the app does runs on the phone:

- **Reading text** from each screenshot (ML Kit text recognition, bundled model).
- **Describing photos and memes** that have little text (ML Kit image labeling, bundled model).
- **Sorting into folders**, telling info screenshots from media (games, comics, social feeds), and **spotting private details** (card numbers checked with Luhn, passwords, backup codes, ID numbers). These are rules on the device.
- **Search**: a full-text index (SQLite FTS4) ranked by how rare each word is across your screenshots.
- **Answers**: Gemma 3 1B reads only the best-matching screenshots and replies. The answer is checked against the screenshot's text before it is shown.
- **The charging digest**: while the phone charges, Gemma reads valuable screenshots in the background and notes key facts.
- **Storage**: the index lives in the app's private storage. Screenshots are never copied, uploaded or changed. Deleting only happens through Android's own confirmation dialog.

The manifest removes `INTERNET` and `ACCESS_NETWORK_STATE` (`tools:node="remove"`). Android enforces this, and Settings shows the live count: 0 bytes sent.

## What requires internet

Nothing while using the app; it works in airplane mode. Only one-time setup needs a connection:

- Downloading the Gemma model file (Hugging Face, after accepting the Gemma license). You then import it in the app or push it with adb.
- Downloading build dependencies (Gradle) and installing the APK from a computer.
- Optional: rendering the demo film, a separate Remotion project kept outside this repo (npm packages).

## Hardware tested on

- **Phone:** Sony Xperia 5 (J9210), Snapdragon 855, 6 GB RAM, Android 11. Gemma runs on the GPU backend.
  - Model load: about 4.7 s at launch.
  - Answers: 2.6 to 3.4 s. Label lookups like "where did I park" are instant.
  - Indexing: about 0.2 s per screenshot (85 demo screenshots in about 20 s; a full 6,963-screenshot phone in about 23 min).
- **Build machine:** Windows 11 PC, Android Studio's bundled JDK 21, Gradle 8.14.

## Try it (no build needed)

1. On an arm64 Android phone (Android 10+), install **ssift-arm64.apk** from the [Releases page](https://github.com/xlgf/appbuildersph-ssift/releases/latest).
2. Get the model: download **Gemma 3 1B instruction-tuned, int4 `.task`** from `litert-community` on Hugging Face, then in ssift open **Settings → Import model file** (details in [The model](#the-model)).
3. Optional demo data: run `tools/push-demo-screenshots.ps1` with the phone on USB and keep **Demo mode** on in Settings.
4. Turn on airplane mode and ask: `wifi password at moms`, `where did I park`, `when is my concert`, `when is my flight to Tokyo`.

## Setup (build from source)

1. Install **Android Studio** (it bundles its own JDK, so the system Java version doesn't matter) with **Android SDK 35**.
2. **File → Open** this `appbuildersph-ssift` folder. Let Gradle sync. If Studio offers to update the Android Gradle Plugin or library versions, accepting is fine.
3. Enable **Developer options → USB debugging** on the demo phone, plug it in, and press **Run**.

## The model

The app expects a MediaPipe `.task` LLM named `model.task`.

1. Download **Gemma 3 1B instruction-tuned, int4** in `.task` format from the `litert-community` org on Hugging Face (accept the Gemma license there). Qwen2.5-1.5B-Instruct `.task` also works.
2. Get it onto the phone either way:
   - **adb (fastest for development):**
     ```
     adb shell mkdir -p /data/local/tmp/llm
     adb push model.task /data/local/tmp/llm/model.task
     ```
   - **In the app:** Settings → *Import model file*, pick the file from Downloads. It is copied into app storage.
3. Relaunch the app. Home stops showing the model notice once it's loaded.

If answers come back garbled, flip `WRAP_GEMMA_TEMPLATE` in `ai/Prompts.kt` (some `.task` bundles apply the chat template themselves).

## How it works

| Layer | Where |
|---|---|
| Screenshot list (MediaStore) | `data/ScreenshotSource.kt` |
| OCR, bundled ML Kit | `index/OcrEngine.kt` |
| Image labels for low-text screenshots (photos, memes, maps), bundled ML Kit | `index/ImageLabeler.kt` |
| Regex folders | `index/Tagger.kt` |
| Sensitive detection (Luhn, passwords, codes, IDs) | `index/SensitiveDetector.kt` |
| Index pipeline | `index/Indexer.kt` |
| Room + FTS4 | `data/` |
| LLM engine (MediaPipe / LiteRT) | `ai/LocalLlm.kt` |
| Search ranking | `ai/ShotSearch.kt` |
| Ask: search, then LLM on top 3 | `ai/AskEngine.kt` |
| Charging digest | `ai/Digester.kt`, `work/DigestWorker.kt` |
| Info vs media (games, comics, social) | `index/MediaClassifier.kt` |
| UI (Compose, bento design from Stitch) | `ui/` |

## Known gaps

- Money questions can return a line item instead of the total ("how much did I pay for pizza" gives $14.50, not $31.20).
- About 1 in 5 game screens on a real phone still count as info, so their wording can turn up in search matches.
- Deleting from the Sensitive folder needs Android 11+ (system confirmation dialog).
